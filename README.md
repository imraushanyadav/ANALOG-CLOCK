# About clock!
An analog clock is a round time-telling tool that uses a face with numbers 1 through 12 and rotating hands to show the hours, minutes, and seconds.

# Parts of clock!
<b>Hour Hand:</b> The short hand that points to the current hour. It moves slowly between number as time passes.

<b>Minute Hand:</b> The long hand that counts the minutes. It goes all the way around the circle once every hour.

<b>Second Hand:</b> The thin, fast-moving hand that counts seconds and circles the face every minute.
